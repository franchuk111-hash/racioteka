# Раціотека: як порівняти доставку раціонів

![Логотип Раціотеки](assets/logo-mark.svg)

**Відкритий інструмент проєкту [Раціотека — racioteka.com.ua](https://racioteka.com.ua/).**

Практичні інструменти для вибору готового харчування в Україні: калькулятор повної вартості замовлення та список запитань до сервісу доставки.

[Раціотека](https://racioteka.com.ua/) — інформаційний каталог. Допомагає порівнювати програми; меню, доступність доставки та остаточну суму потрібно підтвердити у вибраного сервісу.

## Що порівнювати

Ціна «за день» не завжди включає доставку та доплати. Порівнюйте однакову кількість днів і прийомів їжі, перевіряйте склад та вагу страв. Позиція в каталозі не є оцінкою якості.

## Калькулятор повної вартості

Потрібен Python 3.10 або новіший. Зовнішніх бібліотек немає.

```sh
python3 compare_cost.py --daily 500 --days 5 --delivery-fee 80 --deliveries 3 --extras 100 --discount 50
```

Результат: **2790.00 грн за замовлення; 558.00 грн за день**. Це умовний приклад, а не тариф компанії. Для порівняння двох пропозицій запустіть команду окремо для кожної з однаковою кількістю днів.

Не відома ціна доставки? Спочатку уточніть її: відсутня інформація не означає безкоштовну доставку. Калькулятор не визначає потребу в калоріях і не дає медичних рекомендацій.
